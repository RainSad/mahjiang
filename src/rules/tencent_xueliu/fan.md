腾讯血流成河麻将番型规则（附示例）
 
按倍数从高到低整理，特殊场限制、番型定义及简单示例如下：
 
一、256倍番型
 
1. 连七对
- 限制：仅富商和尊爵场可胡
- 定义：一种花色序数牌组成序数相连的7个对子的胡牌，不计门前清、清一色、七对
- 示例：二万二万、三万三万、四万四万、五万五万、六万六万、七万七万、八万八万
 
二、128倍番型
 
1. 九莲宝灯
- 限制：仅富商和尊爵场可胡
- 定义：无碰杠，由同一花色的1112345678999 + 该花色任意一张牌构成胡牌，不计清一色、门前清
- 示例：一万一万一万、二万、三万、四万、五万、六万、七万、八万、九万九万九万 + 五万
 
三、32倍番型
 
1. 天胡
- 定义：庄家发完牌后立即胡牌
- 示例：庄家起手手牌直接组成胡牌牌型（如标准的将牌+四组刻子/顺子）
2. 地胡
- 定义：非庄家第一轮摸牌就胡牌
- 示例：闲家摸第一张牌后，手牌组成胡牌牌型
3. 清十八罗汉
- 定义：清一色+十八罗汉的胡牌，不计清一色、十八罗汉等多项番型
- 示例：全部为万子的牌型，且胡牌时有4个杠牌+金钩钓
4. 将十八罗汉
- 定义：手牌全是2、5、8的十八罗汉，不计碰碰胡、金钩钓等
- 示例：二万二万二万、五万五万五万、八条八条八条等（2/5/8序数牌）组成，含4个杠牌+金钩钓
 
四、16倍番型
 
1. 清七对
- 定义：清一色+七对的胡牌
- 示例：一万一万、二万二万、三万三万、四万四万、五万五万、六万六万、七万七万（全万子）
2. 清金钩钓
- 定义：清一色+金钩钓的胡牌，不计清一色、金钩钓、碰碰胡
- 示例：一万一万一万、二万二万二万、三万三万三万、四万四万四万 + 五万五万（全万子）
3. 将七对
- 定义：序数牌2、5、8组成的七对，不计七对、断幺九
- 示例：二万二万、五万五万、八万八万、二条二条、五条五条、八条八条、二条二条
4. 将金钩钓
- 定义：手牌全是2、5、8的金钩钓，不计碰碰胡、金钩钓、断幺九
- 示例：二万二万二万、五万五万五万、八万八万八万、二条二条二条 + 五条五条
 
五、8倍番型
 
1. 清碰
- 定义：清一色+碰碰胡的胡牌，不计碰碰胡、清一色
- 示例：一万一万一万、二万二万二万、三万三万三万、四万四万四万 + 九万九万（全万子）
2. 将对
- 定义：手牌全是2、5、8的碰碰胡，不计碰碰胡、断幺九
- 示例：二万二万二万、五万五万五万、八万八万八万、二条二条二条 + 五条五条
3. 十八罗汉
- 定义：金钩钓且胡牌时有4个杠牌，不计4根、金钩钓等
- 示例：一万杠、二万杠、一筒杠、二条杠 + 三万三万（金钩钓形式胡牌）
 
六、4倍番型
 
1. 清一色
- 定义：全部由万/筒/条中某一种花色组成的胡牌
- 示例：一万、二万、三万、四万四万四万、五万五万五万、六万六万六万、七万七万（全万子）
2. 七对
- 定义：由七个对子组成的胡牌
- 示例：一万一万、二万二万、三万三万、一筒一筒、二筒二筒、三筒三筒、四筒四筒
1. 金钩钓
- 定义：胡牌时其他牌都被碰/杠，手牌只剩一张牌单钓胡牌，不计碰碰胡
- 示例：一万杠、二万杠、一筒杠、二筒杠 + 三筒（单钓三筒胡牌）
2. 幺九
- 定义：胡牌时，每个刻子、顺子、将都包含1/9序数牌
- 示例：一万刻子、九万刻子、一条刻子、七八九条顺子 + 九条将牌
3. 断幺九
- 定义：胡牌时手牌中没有1、9序数牌
- 示例：二万刻子、三四万顺子、四筒刻子、五六条顺子 + 五条将牌
4. 碰碰胡
- 定义：由4个刻子（或杠牌）和将牌组成的胡牌
- 示例：一万刻子、二万刻子、一筒刻子、二筒刻子 + 三筒将牌
5. 根
- 定义：手牌中4张一样的牌为1根，每有1根胡牌时额外×2
- 示例：胡牌时手牌含四万四万四万四万（1根），番数额外翻倍
6. 自摸
- 定义：自摸胡牌
- 示例：自己摸到所需牌完成胡牌
7. 杠上开花
- 定义：杠牌后补张自摸胡牌
- 示例：杠一万后，补摸的牌是胡牌所需的二万
8. 杠上炮
- 定义：杠牌后打出的牌让其他玩家点炮胡牌
- 示例：杠一筒后打出三筒，被其他玩家胡牌
9. 抢杠胡
- 定义：胡其他人补杠的那张牌
- 示例：其他玩家补杠二万时，自己刚好胡二万
10. 海底捞月
- 定义：摸到牌墙最后1张牌胡牌
- 示例：摸完牌墙最后一张牌（五万），刚好组成胡牌牌型
 
三、1倍番型
 
1. 平胡
- 定义：由4个刻子或顺子加对子组成的胡牌
- 示例：二三万顺子、四五万刻子、三四筒顺子、五六条刻子 + 四条将牌
