【问题 1】天胡/地胡标志位

  实现位置：src/core/logic/turn_handler.py (L24-40)
  
  流程：
  1. 首轮摸牌时，根据玩家身份设置候选标志
     - is_dealer → is_tian_hu_candidate = True
     - !is_dealer → is_di_hu_candidate = True
  
  2. 自摸胡时，确认并清除标志
     - is_tian_hu_candidate → is_tian_hu = True
     - is_di_hu_candidate → is_di_hu = True
     - 清除候选标志
  
  3. 计分时读取标志
     - score_rules._is_tian_hu(p) 返回 p.is_tian_hu
     - score_rules._is_di_hu(p) 返回 p.is_di_hu
  
  验证测试：

    ✅ test_32_fans_tian_hu (番型覆盖)
